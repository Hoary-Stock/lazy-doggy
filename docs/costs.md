## 模型费用

- 已有符合使用条件的 CLI/订阅：填你实际需要的月费；不要假定聊天订阅必然覆盖 API。
- API：分别记录输入、输出 Token 与当前单价。缓存、批处理、不同模型等费用按服务商账单核对。
- 自托管模型：即使没有逐 Token 账单，也仍有 GPU/主机、显存、运维和电费；不能标成“免费”。

API 的简单预算式为：`输入 Token / 1,000,000 × 输入单价 + 输出 Token / 1,000,000 × 输出单价`。单价由用户填写；该式未包含服务商另外收费或优惠项。不把累计会话 Token 当作上下文占用，也不把估算当作实付账单。

## 一台服务器与域名的边界

基础路线连接已有的外部模型/API/CLI，不在这台 CPU 服务器上承诺运行大模型。已有服务器可以把增量服务器租金填 0，但硬件、电力和维护成本并没有消失。域名按年收费；TLS 需要配置和续期监测。设备、应用商店/代码签名证书、自建 GPU 和 Windows 验收环境可能形成另外的成本。

互动报告的计算器只在访客浏览器中计算。预填模型预算 0 的意思是“未计入”，不表示 AI 免费；人民币换算使用可编辑的教学假设汇率，不代表实时汇率。
