# 隐私与公开边界

## 公开资料包含什么

本仓库展示通用模块规范、实现思路、合成界面截图和可重建测试流程。它不是实际服务器的登录指南、生产配置导出或安装包分发站。

公开文件不得出现实际作者或用户的身份、账户、基础设施域名与地址、私人目录、私有仓库地址、真实任务名称、运行标识、认证材料、原会话内容、用户文件或真实反馈截图。官方技术来源链接、本仓库计划使用的公开仓库 / Pages 链接、保留的示例域名和本机演示地址可出现；它们不是实际服务入口。示例使用抽象配置与合成数据；不要把“已打码”视为自动合格，仍需人工检查截图和导出附件。

## 凭据与网络

- 服务端持有模型 API 凭据和上游身份；客户端仅拿自己的受限认证结果。
- Electron 主进程保管认证及系统加密存储，renderer 只接收操作结果。
- 客户端使用固定服务来源和封闭 API；上传、安装器下载拒绝任意 URL 与重定向。
- 日志不保存请求正文、令牌、密钥、完整环境或原始上游错误；客户端显示经过约束的错误码。
- 测试使用独立身份、模拟提供方与自己的合成目录；不要把真实登录材料送到虚拟机或截图。

## 附件与清理

文件名是显示信息，不是访问授权。API 接受不透明附件编号，服务端验证类型、范围、所有者、大小和摘要，不接受任意主机路径。Agent 输入限于已授权工作区，凭据目录与其他运行身份不能因上传而暴露。

清理范围仅为已登记、明确释放且证明无引用的应用私有副本。原件、项目副本、可能生成结果、未知引用、草稿、队列和未确认请求保持保护。保守保留可能导致额度耗尽；此时拒绝新上传并给出原因，不能静默删除保护项。

## 统计与反馈

Token 统计可以使用模型、日期、数值及不透明请求身份完成，不必收集或展示提示词。窗口检查只提供批准的数值与状态；不读取其他用户的提示词、进程参数或完整容器配置。当前 Qwen 窗口检查为只读，不宣称具有归档停止权限。

反馈截图可能包含隐私。限额、文字脱敏和私有存储不等于消除了图像内容风险；用户及公开资料维护者都必须审查。保留时限与访问权限由部署者明确设置，不能从附件 GC 的策略推导反馈数据的删除规则。

## 验收和发布材料

内部验收记录与公开资料分开。公开截图只展示模拟账户、虚构文件及合成 Token；仅导出必要画面，移除状态栏中的身份线索并检查文字层与文件元数据。失败日志、凭据库、虚拟机用户目录、运行缓存和真实数据库不上传。

真实应用界面固有的产品标识可以在合成演示截图中保留，不等于公开作者身份或基础设施。若 Windows 展示覆盖了账户显示标签，配套截图说明必须披露它是仅展示的合成标签；不能暗示真实认证账户被修改，也不能用该标签证明登录或后端权限。

AI 重建时应从空的测试环境开始。真实服务接入、数据保留策略及发布权限是部署步骤，需要独立确认和验收，不能从这份文档获得现有基础设施权限。

## 本次公开材料的审阅

维护者完成文本、链接、归档和图片元数据检查，并逐张查看合成演示截图。DeepSeek 与 Qwen 分别进行只读文字审阅，收到公开候选与截图 OCR，未获得工具或文件修改权限；它们只给建议，由维护者核对后修改。文字审核不替代图片的人工检查，原始运行记录与审核回执不公开。
